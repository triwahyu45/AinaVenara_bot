# Aina Venara Reference Keep List

Folder berikut adalah reference aktif dan tidak boleh dihapus, dipindahkan ke archive, atau dibersihkan tanpa konfirmasi eksplisit dari pemilik project:

- `Reference`
- `Reff 3D`
- `Reff 3D Detailed`
- `Reff 3D HD Generated Individual`
- `legacy`

Cleanup storage hanya boleh menyasar file yang jelas bisa dibuat ulang, seperti:

- preview render sementara
- extracted GLB texture sementara
- QA screenshots sementara
- cache/build artifact
- output eksperimen yang sudah digantikan dan sudah dikonfirmasi aman

Jika ragu apakah sebuah file adalah reference atau generated artifact, perlakukan sebagai reference dan jangan hapus.
