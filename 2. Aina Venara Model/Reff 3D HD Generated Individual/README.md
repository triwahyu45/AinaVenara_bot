# Aina Venara Generated HD Individual Reference Pack

This active pack contains 50 individual generated visual guides normalized to
`2048x2048`. No active PNG is a crop from the older multi-panel sheets.

Only eight approved orthographic views participate in automated Blender fitting.
The remaining generated plates are visual construction guides for manual review
and polishing. Rejected or drifting generations belong under `_source/rejected`.

Run `_source/build_generated_pack.py` after raw plates have been copied into
`_source/generated`. The builder validates count, duplicate hashes, clean white
corners, schema-v2 manifest metadata, and category contact sheets.
