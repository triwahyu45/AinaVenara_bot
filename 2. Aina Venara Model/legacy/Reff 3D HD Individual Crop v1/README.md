# Aina Venara HD Individual Reference Pack

This folder contains exactly 45 clean `2048x2048` PNG files for Blender image
planes and overlay fitting. Each file focuses on one view or one construction
detail. The canonical cyan-mint design remains the only accepted identity.

Run `_source/generate_hd_references.py` with the bundled workspace Python to
rebuild the PNG files and `reference_manifest.json` from the detailed canonical
sheets. The source sheets remain unchanged.

The fitting pipeline reads `reference_manifest.json`. Use the full-body and face
views for scored fitting; use micro-detail files as visual construction guides.
