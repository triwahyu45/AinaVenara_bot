# 🎨 VRoid Studio — Panduan Lengkap Aina Venara
> Buat berdasarkan 50 reference image HD yang sudah ada di folder proyek

Buka reference image di folder ini bersamaan dengan VRoid Studio:
`2. Aina Venara Model\Reff 3D HD Generated Individual\`

---

## 🚀 Langkah Awal

1. Buka **VRoid Studio**
2. Klik **Create New** → pilih **Female**
3. Simpan project sebagai `Aina_Venara_v8.vroid`

---

## 💾 STEP 9 — Export VRM

1. **File → Export as VRM**
2. Metadata:
   - Title: `Aina Venara`
   - Version: `8.0`
3. Enable Shape Keys (untuk ekspresi)
4. Output:
```
%LOCALAPPDATA%\AinaDesktopCompanion\models\Aina_Venara_v28.vrm
```
5. Backup copy:
```
2. Aina Venara Model/VRM Draft/Aina_Venara_v28.vrm
```
